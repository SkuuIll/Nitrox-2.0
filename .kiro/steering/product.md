# Product Overview

Nitrox is an open-source multiplayer modification for the underwater survival game Subnautica. The mod enables multiple players to explore, build, and survive together in Subnautica's ocean world.

## Key Features
- Client/Server architecture for multiplayer gameplay
- Real-time synchronization of player movement, building, and interactions
- Vehicle syncing (Seamoth, Exosuit, Cyclops)
- Base building and furniture interactions
- Power management and resource sharing
- Chat system and player animations
- Cross-platform launcher application

## Current Status
The mod is in active development with a solid foundation established. It includes core multiplayer functionality and is distributed through a user-friendly launcher available on the Nitrox website.

## Architecture
- **Client**: Game modification that integrates with Subnautica
- **Server**: Standalone server application for hosting multiplayer sessions
- **Launcher**: Desktop application for managing mod installation and server hosting
- **Patcher**: Runtime code modification system using Harmony
