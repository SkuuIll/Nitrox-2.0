NITROX - COMPILACIÓN COMPLETA
=============================

Fecha de compilación: 18 de agosto de 2025
Versión: 1.8.0.0
Configuración: Release

CONTENIDO DE LA CARPETA:
========================

/Launcher/
- Nitrox.Launcher.exe - Aplicación principal del launcher
- Archivos de dependencias y recursos necesarios
- Ejecutar este archivo para iniciar el launcher de Nitrox

/Server/
- NitroxServer-Subnautica.exe - Servidor dedicado de Nitrox
- Archivos de configuración y dependencias del servidor
- Ejecutar este archivo para iniciar un servidor dedicado

/Client/
- NitroxClient.dll - Biblioteca del cliente de Nitrox
- Archivos necesarios para la integración con Subnautica
- Se instala automáticamente a través del launcher

/Patcher/
- NitroxPatcher.dll - Sistema de parches de Harmony
- Archivos necesarios para modificar Subnautica en tiempo de ejecución
- Se instala automáticamente a través del launcher

INSTRUCCIONES DE USO:
====================

1. Para usuarios normales:
   - Ejecutar Launcher/Nitrox.Launcher.exe
   - Seguir las instrucciones en pantalla para instalar y configurar

2. Para servidores dedicados:
   - Ejecutar Server/NitroxServer-Subnautica.exe
   - Configurar según sea necesario

REQUISITOS:
===========
- .NET 9.0 Runtime (para Launcher y Server)
- .NET Framework 4.7.2 (para Client y Patcher)
- Subnautica instalado (para el cliente)

NOTAS:
======
- Esta compilación incluye todas las dependencias necesarias
- Los archivos Client y Patcher se instalan automáticamente por el Launcher
- Para más información, consultar README.md
